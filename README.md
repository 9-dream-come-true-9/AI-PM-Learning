# AI PM Learning

我的 AI 产品经理学习记录，包含数据分析、原型工具与基础方法练习。这个仓库主要用于保存学习过程和练习文件，内容按主题组织。

## 内容导航

| 主题 | 内容 |
| --- | --- |
| [`excel学习`](./excel学习) | Excel 函数、图表、数据透视表、甘特图，以及业绩和财务分析练习 |
| [`numpy`](./numpy) | 数组、条件逻辑与排序练习 |
| [`pandas`](./pandas) | 文件创建和数据读取练习 |
| [`sql practise`](./sql%20practise) | SQL 练习题与笔记 |
| [`Axure 11 study`](./Axure%2011%20study) | Axure 11 学习记录 |
| [`入门-xmind墨刀study`](./入门-xmind墨刀study) | XMind、墨刀入门学习记录 |

## 使用方式

按主题进入对应目录或文件即可查看笔记。`.xlsx` 文件可用 Excel 或兼容的表格软件打开；其余无扩展名文件为学习记录，可使用文本编辑器查看。

仓库内容会随学习持续更新。练习中的分析结论仅对应当时所用的素材与方法。
